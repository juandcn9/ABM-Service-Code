# Security policy

This repository is limited to synthetic demonstration data. Never submit credentials, secrets, real customer information, card data, bank account/routing data, investigation records, or private approval material in source, fixtures, issues, pull requests, logs, screenshots, or evidence.

If exposure is suspected, stop work, avoid repeating the value, identify only the location and secret/data type, and notify JDC. Removing the visible value alone is not remediation because history and caches may retain it.

Security defects and suspected exposures are not discussed in public artifacts. Use the repository owner's private reporting channel.
